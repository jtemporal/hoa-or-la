# Hoa hoa hoa or la la la

A silly quiz to find out which kind of fall person you are: the moody vampire-movie kind (hoa hoa hoa) or the small-town, coffee-in-hand kind (la la la).

Live at [jtemporal.com/hoa-or-la](https://jtemporal.com/hoa-or-la).

## How it works

- Seven two-way questions, eight possible results
- The result comes with an emoji shower, a copyable text version, and a generated image card to share
- Everything is in one `index.html`. No build step, no dependencies besides Google Fonts

## Run it locally

Open `index.html` in a browser.

## Deploy

Served by GitHub Pages from the root of `main`. The `.nojekyll` file tells Pages to skip the Jekyll build.

If the address ever changes, update `SHARE_URL` in the script and the `canonical` and `og:url` tags in the head of `index.html`.
